# Additional firsthand inspection

Inspected 2026-09-11 by the author, in the collaborative Chromium preview. Desktop 1280 × 800; mobile layout 390 × 844 (desktop browser user agent, not a physical phone).

## GOV.UK: task clarity and grouping

At [GOV.UK](https://www.gov.uk/), the desktop home page gives search the dominant functional position, with a visible label and wide input. Popular destinations form a compact three-column list. Shared alignment, type weight, underlines, whitespace, and a section divider communicate structure without individual tile backgrounds. The mobile view stacks those destinations into one column while keeping labels legible and the search field usable. These are observed layout properties, not a measured accessibility or usability result.

The cookie panel's reject action produced explicit confirmation; its hide action removed the panel and revealed the main task. Both states were exercised. No search result flow or navigation menu was tested. This is a limited example of clear state feedback, not a recommendation to add cookie panels to other products.

Evidence: [desktop](screenshots/root-govuk-desktop.png), [mobile](screenshots/root-govuk-mobile.png).

**Transfer:** Group related actions through alignment and proximity. Make links recognizable. Let task frequency and reading order set emphasis. Dense useful content and breathing room can coexist.

**Limit:** A government service directory is a contrasting functional reference, not a visual style Zach has selected. Its palette, typeface, and hero layout should not become universal skill defaults.
