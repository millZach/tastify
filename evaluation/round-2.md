## Shared prompt

> Build a jaw-dropping interactive landing page. You choose the subject, visual style, and interactions.

Use this exact brief in every condition. It deliberately leaves branding, structure, imagery, and interaction mechanics to the builder.

The two skills share the same visual criteria and two-concept exploration stage. Solo performs the work sequentially itself. Team delegates exploration to independent builders and evaluation to separate critics.

Start every build in a fresh context and isolated project, with the same model, reasoning, user instructions, starter files, and available tools. Load only the selected candidate skill. Keep this study, prior results, other candidate skills, and competing sites out of builder context. Baseline retains its ordinary tool choices; record any agents it uses.

Use a comparable total resource allowance per condition, summed across the main agent and every subagent. Record actual elapsed time, token use where available, and agent count; identify unavailable measurements. Keep asset-generation allowances equivalent. Record any solo substitution in the team condition separately; it is not a completed test of the proposed team workflow.

## Judge the difference

Compare final sites under randomized neutral labels. Use matching desktop and phone sizes and inspect the defining interaction as well as screenshots. Show all outputs; record Zach's preference and its strength: barely noticeable, noticeable, or substantial. Record broken behavior separately from visual preference.

A slight preference with barely noticeable differences does not meet the acceptance bar. The skill needs a noticeable benefit worth its added effort, without material behavioral regressions. Open briefs increase variation, so repeat the same prompt in fresh runs before claiming consistent benefit. Retain losses and incomplete runs; do not select only each condition's best result. Add a different brief before claiming broader effectiveness.

Skill validation and independent document review establish usable instructions, not design improvement. Final candidate hashes and review notes are in [the variant review](../research/skill-variants-review.md).
